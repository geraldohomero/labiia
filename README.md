## Site do LABIIA LAB

Este repositório contém o código-fonte do site do LABIIA LAB, um laboratório de pesquisa dedicado ao estudo da inteligência artificial e suas aplicações. O site é construído usando HTML, CSS e JavaScript, e é hospedado no GitHub Pages.
